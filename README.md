# Stugora

Lists cottages across the Nordics and the Baltics (Finland, Sweden, Norway,
Denmark, Iceland, Estonia, Latvia, Lithuania) on Airbnb, Booking.com and Vrbo
for their owners.
Pricing (plan of 28 Oct 2026): €99 a year per cottage plus 12% of the owner's
payout on bookings from Stugora's channels, both plus 25.5% VAT. Nettimökki
bookings are never charged. Pilot owners pay 10% and their first year is free.

## What is here

- `backend/` — Django 5.2 + Django REST Framework
  - `owners` app: `OwnerSignup` (the stugora.fi form), `Owner`, `Cottage` (intake),
    `Booking` (commission and VAT per stay, yearly fee per listing year)
  - `POST /api/signups/` — public, throttled (10/hour per IP), honeypot field, emails the team
  - `/admin/` — work the sign-ups, owners, cottages and bookings
- `frontend/` — Next.js 16 site for stugora.fi, in ten languages
  - every page lives under its language: `/en`, `/fi`, `/sv`, `/nb`, `/nn`, `/da`, `/is`,
    `/et`, `/lv`, `/lt`, e.g. `/sv/hosts` and `/et/cottages/lakeside-villa`; `/` and any
    address without a language redirect to the visitor's saved or browser language
    (`src/proxy.ts`), and the old Finnish addresses `/mokit/…` and `/omistajille` redirect
  - guest homepage `/<lang>`: search, categories, filters, saved cottages,
    Country → Region → Town pickers and a map view (Leaflet + OpenStreetMap tiles);
    search, dates and guests are kept in the address, so a change of language keeps them;
    example cottages in `src/lib/listings.ts`
  - owner page `/<lang>/hosts`: earnings estimator and sign-up form
  - `src/lib/places.ts`: 98 regions and their towns with coordinates, generated by
    `scripts/build-places.js` from GeoNames (CC BY 4.0). To change it, in a normal terminal:
    `cd ~/stugora/scripts && npm install && node build-places.js`

## Languages

All the words are in `frontend/src/i18n/messages/<lang>.ts`; English (`en.ts`) is the
source and the fallback for anything a language is missing. How to translate:
`frontend/src/i18n/TRANSLATING.md`. Adding a language: its code in
`src/i18n/locales.ts`, one messages file, and the code in the backend's `Language`
choices; routes, the language picker, hreflang and sitemaps follow.

Numbers, prices, dates, plural forms and country names come from the browser's own
locale data (`Intl`), so they are right for every language without translating them.

Checks, in a normal terminal:

```bash
cd ~/stugora/frontend
npm run i18n:check     # lists missing keys, plural forms, list lengths, {placeholders}
npm run test:i18n      # localization tests
```

The non-English text is machine-written and should be read by a native speaker before
launch, Icelandic, Latvian, Lithuanian and Nynorsk first.

## Run it locally

In a normal terminal:

```bash
cd ~/stugora
./dev.sh
```

The first run sets up a Python virtual environment and installs the npm
packages, which takes a few minutes. It then opens http://localhost:3100.

| What | Address |
| --- | --- |
| Guest site | http://localhost:3100 (redirects to /en, /fi, /sv …) |
| Owner sign-up page | http://localhost:3100/en/hosts, /fi/hosts … |
| Admin (sign-ups, owners, bookings) | http://localhost:8100/admin |

Ports 3100 and 8100 leave 3000 and 8000 free for Bona. Press Ctrl+C to stop.
To log in to the admin, in a normal terminal:

```bash
cd ~/stugora && backend/.venv/bin/python backend/manage.py createsuperuser
```

Tests, in a normal terminal:

```bash
cd ~/stugora/backend && .venv/bin/python manage.py test
```

## Before the page goes public

- Switch map tiles from tile.openstreetmap.org (fine for development only) to a
  hosted tile provider such as MapTiler or Stadia Maps
- Move the "Nearby" lookups (frontend/src/lib/nearby.ts) behind a small Django
  endpoint that caches Wikipedia's answer per cottage for a week, so each page
  view doesn't call Wikipedia from the guest's browser
- Buy stugora.fi and set up hello@stugora.fi (used on the page)
- Privacy policy page (GDPR) and a link to it next to the consent box
- Finnish copy checked by a native speaker
- Confirm with the accountant that Elda-Auto Tmi charges VAT on Stugora fees
